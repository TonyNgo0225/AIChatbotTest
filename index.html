What This Prototype Shows

This is a simple staff-facing website prototype. It is meant to show how employees could manage the backend of a chatbot that is embedded on the existing college website.

Important: This is only a static demo. It does not connect to real student data, real AI, Microsoft login, or a database.

Simple System Flow

Existing college website → students and parents ask questions through the chatbot.

Chatbot backend → searches approved content and decides whether to answer or escalate.

Staff admin portal → staff upload content, respond to tickets, and review resolved tickets.

Example Use Case

A student asks: “Why did my financial aid disappear?”

The chatbot should not guess because this may involve private student records.

Instead, the chatbot creates a ticket for staff to review.
